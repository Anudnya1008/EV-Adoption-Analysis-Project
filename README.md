
# EV Adoption Analysis Project

A machine learning project analyzing electric vehicle (EV) adoption across U.S. states, exploring how charging infrastructure, economic factors, and demographic characteristics influence EV adoption and growth.

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

## Dataset
- EV adoption data across 51 U.S. states/jurisdictions
- Historical data from 2016 to 2023
- 408 records covering EV adoption, charging infrastructure, and economic indicators

## Features
- **Data Cleaning:** Handled missing values, selected relevant features, and prepared datasets for analysis.
- **Exploratory Data Analysis:** Analyzed EV adoption trends across states and years.
- **Feature Engineering:** Created EV growth indicators and next-year adoption metrics.
- **Predictive Modeling:** Applied machine learning classification techniques to analyze high versus low EV adoption growth.
- **Model Evaluation:** Used classification metrics and train/test splits to evaluate predictive performance.
- **Trend Analysis:** Examined relationships between EV adoption, charging availability, income, education, electricity prices, and gasoline prices.

## Running Locally
1. Clone the repository.
2. Install the required Python libraries.
3. Open `EVAdoption_Final.ipynb` in Jupyter Notebook or Google Colab.
4. Load `EV_Data.csv`.
5. Run the notebook cells to reproduce the analysis.
